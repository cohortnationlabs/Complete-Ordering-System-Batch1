## ordering system application 

Learners strengthen their fundamentals by moving beyond syntax into real problem-solving. You’ll learn to write clean, modular functions and work confidently with parameters, loops, and conditionals. The focus is on building logical thinking and understanding how to structure simple programs effectively.

you’ll learn how applications store and retrieve data using SQL or NoSQL databases. You’ll connect your APIs to a database and implement create, read, update, and delete operations. Along the way, you’ll learn to manage environment variables and organize your project with a beginner-friendly folder structure.

## PreSetup
- clone the repo
- cd 'complete-ordering-system-batch1'
- touch .env 
- paste `PORT=3000` inside .env

## To Run 
- cd 'complete-ordering-system-batch1'
- npm i
- npm run dev
